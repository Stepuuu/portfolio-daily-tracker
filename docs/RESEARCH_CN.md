# 股票研究工作台（3.2）

研究工作台把“提出问题 → 选择数据 → 实验 → 比较 → 复盘”放在一个页面中。手动模式和 Agent 模式使用相同的计算引擎、任务记录与导出接口。它适合学习股票日线研究方法、检查假设和保存可复查的实验；当前不提供期权曲面、Greeks、多腿期权回测或实盘下单。

## 不需要密钥的第一次实验

在仓库根目录运行：

```bash
make setup
make lab
```

打开 [研究工作台](http://localhost:3000/lab)。后端默认监听 `127.0.0.1:8000`，前端默认使用 `3000` 端口；端口被占用时通过 `BACKEND_PORT`、`FRONTEND_PORT` 选择空闲端口。需要 Python 3.10+、Node.js 22.12+ 和 Bash 4.3+，可以直接在已有容器中启动，无需 Docker 守护进程。

1. 保持“手动实验”，选择合成股票数据。
2. 选择“动量延续”模板，写下问题，例如“近期价格动量能否改善未来五日收益预测？”
3. 检查预测周期、观察窗口、市场、手续费与滑点，点击启动。
4. 等待任务完成，先比较验证集和测试集误差与基线，再看净值曲线、样本数、学习提示和方法假设。
5. 保存导出，修改一个参数后再运行，用历史记录比较两次实验。

合成数据用于熟悉流程，结果不代表真实市场证据。手动实验不调用模型。`make lab` 跳过组合与对话服务初始化，不需要先配置账户。常规 `make start` 也包含 `/lab`。

`make demo` 使用隔离的虚构组合和研究存储，组合保持只读，同时允许合成数据的手动实验。真实数据导入、模型连接与 Agent 研究请使用普通研究模式。

## 选择数据并固定研究口径

| 入口 | 适用情况 | 需要检查 |
|---|---|---|
| 合成数据 | 离线学习流程 | 不把结果当作市场发现 |
| CSV 导入 | 自备日线、已有研究样本 | 列名、日期顺序、价格范围、复权口径 |
| 本地缓存 | 复用已经下载的日线 | 缓存覆盖区间和新鲜度；读取不会修改原缓存 |
| 市场下载 | 明确获取所选股票与区间 | 上游可用性、股票代码和复权选择 |

CSV 使用 UTF-8，列名为 `date,symbol,open,high,low,close,volume`，日期格式为 `YYYY-MM-DD`。每个代码的日期必须唯一且递增。OHLC 必须是有限正数且满足高低价范围，成交量必须有限且非负。当前每份数据最多 10 个代码、25,000 行、8 MB；错误输入会被拒绝。

CSV 的 `volume` 单位为股数；A 股来源若以“手”给出，导入前应乘以 100。AKShare 的 A 股日线下载分支按[官方单位说明](https://akshare.akfamily.xyz/data/stock/stock.html)将手转换为股。旧缓存没有可靠单位元信息时，不会被自动改写：请核对来源单位，或重新下载后创建新数据版本。经典回测撮合器使用成交股数限制参与率；当前研究工作台的分数仓位模拟不使用绝对成交量作为容量上限。

导入后保留不可变数据版本、内容校验值、来源与复权信息。每次实验都会验证数据内容。已知复权信息必须与实验设置一致；CSV 的复权设置由使用者声明。页面会按股票代码推测市场，并跟随已知数据复权信息，启动前仍应核对。

版本记录方便复现实验，但无法补回数据源没有提供的历史修订、当时可见的成分股或退市股票。今天选出的股票和今天下载的复权历史数据，仍可能带来选择偏差与历史修订偏差。

## 三个学习模板与结果解读

| 模板 | 研究问题 | 预测目标 |
|---|---|---|
| 动量延续 | 最近的价格特征能否预测随后收益？ | 未来收盘到收盘收益率 |
| 短期反转（均值回归） | 偏离近期均值后是否出现回归？ | 未来收盘到收盘收益率 |
| 波动预测 | 历史风险特征能否优于波动率延续基线？ | 未来年化实现波动率 |

内置方法使用 NumPy Ridge 回归。模型和特征标准化只在训练段拟合，用验证集 MAE 选择正则化参数；跨越训练、验证、测试边界的标签按成熟日期剔除。测试段不参与拟合或选择参数。

MAE 越低表示预测误差越小，但必须和简单基线比较。验证集用于选择方法，测试集用于最终评价；样本量、不同时间段表现、成本敏感性都需要一起看。重叠标签并不是独立样本，误差改善比例不是统计显著性结论。

预测与交易模拟是不同输出。内置模拟按下一交易日开盘调整只做多的分数仓位，扣除所设换手成本，最终按最后收盘价估值。它没有完整模拟整手交易、涨跌停排队、融资或券商保证金。多股票曲线在共同测试日期上等权汇总，不含跨股票再平衡成本。

结果页提供指标、与基准对照的净值曲线、Agent 解释（如有）、候选实验和复现信息。合成数据等数据问题突出提示；通用假设收在“方法假设与限制”中，展开可读原始说明。保留这些假设后再解释收益，避免只根据一条好看的曲线下结论。

## 自动研究：规划、实验、反馈、最终评价

选择 Agent 模式、数据、模板和连接，设置实验次数上限与超时，然后启动。无需逐步确认研究计划；系统在所设预算内完成：

1. 生成问题假设和已注册模板的参数方案。
2. 调用确定性计算引擎，保留成功与失败的实验记录。
3. 阅读验证集证据，进行有限次调整。
4. 按有效的验证集指标冻结最终方案。
5. 评价选中方案的最终测试结果，并给出带实验引用的解释。

同一任务内，数据集、预测目标、预测周期、时间划分、市场与成本口径保持固定。迭代时只向模型提供验证证据，候选摘要不包含其他候选的测试结果。以后反复用同一历史测试区间做新研究，仍不等于得到新的独立验证。

模型调用在发起前计数，失败调用也消耗预算。无效计划、缺乏有效数值证据、提供方错误或预算耗尽都会显示失败，不会用文字报告替代成功实验。Agent 只能选择已注册的方法；当前没有开放任意生成代码的执行沙箱。

## 连接 API 或官方订阅客户端

在工作台的“接入与安排”或设置页面管理连接。可用提供方来自后端注册表；模型名称可编辑，不依赖固定模型目录。

| 连接 | 配置方式 | 说明 |
|---|---|---|
| OpenAI 兼容 API | 服务端密钥环境变量名、地址、模型 | 使用兼容的聊天与工具调用协议 |
| Anthropic API | 服务端密钥环境变量名、模型 | 使用 Anthropic Messages 协议 |
| Codex CLI | 安装并通过官方客户端登录 | 通过 `codex exec` 使用已有登录 |
| Claude Code CLI | 安装并通过官方客户端登录 | 通过 `claude -p` 使用已有登录，禁用原生工具 |

API 密钥由部署环境设置，页面只填写环境变量名，例如 `OPENAI_API_KEY`，不粘贴密钥值。密钥值不会作为连接配置保存或返回浏览器。显式配置的本地回环模型服务可以不设密钥。

订阅连接沿用官方客户端登录，不复制令牌、不自行实现 OAuth，也不把订阅登录当作 API 密钥。模型留空时使用客户端默认模型。“检查连接”检测安装、环境变量或登录状态，不发起付费模型调用；检查通过不能证明指定模型与额度可用。Claude Code 订阅连接仍需在自己的账号环境中完成实际任务验证，支持适配器不代表每个订阅环境都已验证。

远程模型会收到所选研究问题、数据集元信息和计算证据等研究上下文。研究存储在本机，不等于 Agent 全程离线。使用远程数据源时，下载请求也会发送所选股票与时间区间。手动实验不向模型发送上下文。

## 任务历史、故障与定时研究

表单自动保留本地草稿；任务链接包含任务 ID，可以回到同一记录。网络短暂故障时页面提示错误并继续轮询。历史列表支持查看、加载配置、比较、取消、重试和导出。重复提交通过请求标识避免重复创建。

任务与事件保存在 SQLite。后台通过任务租约和阶段检查点恢复工作，服务重启后继续已保存阶段。重启时正在进行的远程调用可能已经计费却没有保存响应，再尝试仍受已保存预算约束。总超时包含停机时间。

取消会停止计算或模型子进程，并阻止取消后的结果提交；已经消耗的远程额度无法撤回。重试会创建有来源关联的新任务，使用新预算，原记录保留。

在“接入与安排”中，从当前配置创建定时研究，设置间隔、触发次数上限和启停状态。计划只有在后台运行时执行，重启后保留；停机错过多个周期时只补发一次到期任务，不集中重放。页面计数是**已触发次数，不是成功次数**。

默认计划重复使用所选数据版本。在创建安排时勾选“每次运行前更新数据”（API 对应 `refresh_data`），可沿用原股票、起始日期与复权口径，在每次触发时创建截至当前日期的新版本。只有保留来源选择信息的缓存或市场数据可启用，缓存本身仍可能过时；CSV 和合成数据的开关禁用，需导入新版本后新建安排。已有安排会标明“固定版本”或“随运行更新”。定时研究不自动交易、不确认账本，也不发送消息。

## 命令行

CLI 连接已经运行的后端，不自行启动服务。先列出数据与连接，将下面的 `ds_...`、`run_...` 和连接 ID 换成实际返回值：

```bash
python scripts/research.py datasets
python scripts/research.py templates
python scripts/research.py connections
python scripts/research.py run --dataset 'ds_...' --template momentum \
  --goal '近期动量能否改善未来五日收益预测？' \
  --params '{"lookback":20,"horizon":5}' --wait
python scripts/research.py run --dataset 'ds_...' --template volatility \
  --agent --connection 'codex_cli' --max-experiments 3 --timeout 600 --wait
python scripts/research.py status 'run_...'
python scripts/research.py cancel 'run_...'
python scripts/research.py export 'run_...' --output research-result.json
```

通过 `--url http://127.0.0.1:8000` 或 `TRACKER_LAB_URL` 指定后端，全局参数写在子命令前。`--request-timeout` 控制单次 HTTP 等待；`run --timeout` 限制任务总时间。自动化提交可指定稳定的 `--request-id`，相同标识必须对应相同请求。

输出为 JSON，失败或取消的任务返回非零退出码。`--wait` 被 Ctrl+C 中断或本地等待超时，不会自动取消后台任务，需要显式执行 `cancel`。导出文件采用仅所有者可读写的权限，默认不覆盖已有文件；确需替换时使用 `--force`。完整参数见 `python scripts/research.py --help` 与 `run --help`。

## 扩展与运行边界

- Python 注册表可以添加研究模板、参数 schema 和模型提供方；页面动态渲染插件参数与提供方选项。插件必须显式安装并通过 `TRACKER_LAB_PLUGINS` 启用，属于受信任服务端代码。
- HTTP `/api/lab`、工具目录 `/api/lab/tools` 和 stdio MCP 桥共享校验、预算、取消和任务状态。外部 Agent 无需复制计算引擎。
- MCP 桥从 `dashboard` 目录执行 `python -m core.lab_mcp --url http://127.0.0.1:8000`，需要后端已启动；它不开放任意 HTTP、Shell、凭据或账本确认。
- 详细接口与插件示例见 [扩展指南](RESEARCH_EXTENSIONS.md)，英文方法说明见 [Research workbench](RESEARCH.md)。

`TRACKER_LAB_DIR` 可指定研究存储目录，默认是 `dashboard/data/lab`。SQLite、导入数据、连接配置、日志和导出都应保留在本地，不要提交进公开仓库。**导出不自动脱敏**，可能包含研究问题、股票代码、数据与实验配置，分享前应自行检查。

本版本面向自托管单用户场景。默认保持回环监听；需要远程访问时另行配置身份认证基础设施。多租户权限、分布式远程工作节点和任意代码沙箱不属于当前发布范围。部署边界见 [SECURITY](../SECURITY.md)。
